# Původní podklady map

Soubory `*.png` v této složce jsou textury z projektu Stellarium (https://github.com/Stellarium/stellarium, složka `textures/`). Autoři a licence jednotlivých map jsou v `CREDITS.md` v kořeni repozitáře.

Nejsou tu původní mapy J. Hastings-Trewa (Planetary Pixel Emporium, https://planetpixelemporium.com/planets.html): autor povoluje jejich užití v programech, ne však šíření samotných map. Kdo chce mapy sestavit znovu, stáhne si je z jeho stránek:
`jupitermap.jpg`, `saturnmap.jpg`, `marsmap1k.jpg`, `uranusmap.jpg`, `neptunemap.jpg`, `venusmap.jpg`, `venusbump.jpg` a mapy Země `earth_atmos_2048.jpg`, `earth_clouds_1024.png`, `earth_lights_2048.png`, `earth_normal_2048.jpg`, `earth_specular_2048.jpg` (poslední pětice je i v ukázkách Three.js).
